# Nifty Short Strangle Backtesting Project

## Project Overview
This project performs a backtest of a specific options trading strategy, the Nifty Short Strangle, using historical 1-minute data for Nifty spot prices and options. The goal is to simulate the strategy's performance over a defined period and generate a detailed trade log for analysis.

This script is designed for educational purposes, particularly for those new to quantitative analysis and backtesting in Python.

📈 The Strategy: Nifty Short Strangle
The backtest implements the following rules:

### Strategy: Short Strangle on the Nifty index.

Instruments: Nifty Index Call (CE) and Put (PE) options.

#### Selection:

Short 1 lot of a Call option at ATM + 100 points.

Short 1 lot of a Put option at ATM - 100 points.

(ATM is the At-The-Money strike, rounded to the nearest 100).

Entry Time: Exactly at 1:00 PM on each trading day.

Exit Time: Exactly at 3:00 PM on the same day.

### Stop-Loss:

A 30% stop-loss is placed on the premium of each leg.

If one leg's stop-loss is hit, the stop-loss for the other leg is moved to its entry price (cost).

🗂️ Files in This Project
This project uses the following files:

### Input Data Files
Nifty_spot_data_min_2024.csv: Contains 1-minute OHLC (Open, High, Low, Close) data for the Nifty spot index.

Call-Option-Data-1min.csv: Contains 1-minute OHLC data for various Nifty Call options.

Put-Option-Data-1min.csv: Contains 1-minute OHLC data for various Nifty Put options.

### Output File
nifty_short_strangle_tradelog_final.csv: The final output file generated by the script. It contains a detailed log of every trade executed during the backtest period, formatted as requested.

💻 Code Structure
The Python script is organized into clear, commented sections for easy understanding:

Data Loading and Preprocessing: Loads the three CSV files, parses all date and time columns correctly, and sets the timestamp as the index for efficient time-series analysis.

Backtesting Function: Contains the core logic for the strategy. It iterates through each trading day, identifies entry and exit points, calculates stop-losses, and records each trade.

Run Backtest and Generate Output: Calls the main function to execute the backtest for the specified period (2024-11-04 to 2024-12-31).

Output File: Saves the final results into the tradelog.csv file.
